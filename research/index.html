Research and development pathway

01 / Worked example

Can a plan-review tool
explain a possible issue?

The intelligent plan-review project is in development. This example illustrates the method, not an operational review service.

In development

A flag should come with context.

Input
A supported plan, its scale and a specified jurisdiction and rule version.
Candidate output
A possible issue, the location and the criterion the prototype attempted to check.
Expert review
Is the geometry interpreted correctly? Does the criterion apply? Is information missing?
Result
Refine the flag, dismiss it or investigate further. The professional retains responsibility.

02 / Evaluation changes the tool

One result is not enough.

Test representative cases, missed issues, false alarms and uncertain inputs. Record the limits before considering integration.
